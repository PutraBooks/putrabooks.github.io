# ElevenReader material has moved

Everything ElevenReader lives in the private repo `PutraBooks/Elevenlabs`:
https://github.com/PutraBooks/Elevenlabs

## 2026-11-01 — the status generator moved

- `tools/elevenreader_status.py` → `PutraBooks/Elevenlabs` `Scripts/site_reader_status.py`

It still writes this repo's `go/status.json`; run it against this clone:

```bash
python3 ~/…/Elevenlabs/Scripts/site_reader_status.py --repo /path/to/putrabooks.github.io
```

Re-run it after every ElevenReader status sweep, so `/go/elevenreader.html` sends readers
to the book when a read is live and to the ebook editions while it is still in review.

## What stays here on purpose

The storefront itself: `elevenreader-*.html` store pages, `go/elevenreader.html`, the
`elevenlabs://read/<id>` bridge, and the covers and samples those pages serve. This repo
is public; no internal docs, scripts or credentials belong in it.
