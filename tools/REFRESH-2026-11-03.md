# Refresh result, 2026-11-03 — what `--refresh` now changes, and why

Run into a scratch copy of `books/`, `tools/` and `series/` first, then diffed against the live
tree. The generator, the map and the template were reconciled until a refresh reproduces the live
page, so that the only remaining differences are corrections.

## Two defects fixed before the refresh could be trusted

1. **Markers dropped.** `--refresh` used to drop `/track.js`, the Ko-fi starter line, the Payhip
   deep link and the readthrough nav. Fixed by rendering from the harvested map
   (`tools/page_markers.json`, `tools/harvest_page_markers.py`) instead of from card data, with
   `tools/test_build_missing_pages.py` proving all four markers on three page shapes.
2. **Table of contents stacked.** `parse_cards()` split a series page on the card opener and kept
   everything after it, so a card's `<li>` scan also read the following cards' lists. A 13-chapter
   book got 66 entries, a 14-chapter book 59. Nine cards were affected. The card block is now
   bounded at its own `</details>` and the contents come only from that card's `<ol class="toc">`.
   The test asserts every card's list is exactly the opening of its page's list, and pins the four
   counts the defect report named (14, 13, 25, 12).

## The refresh, measured

783 generated pages refreshed. **764 are byte-identical to the live page.** 19 differ:

| Pages | What changes | Why |
|---|---|---|
| 2 | `<ol class="toc">` shrinks (66 → 13, 30 → 14) and the JSON-LD `description` changes | `building-the-industrial-equipment-of-tomorrow.html` and `making-money-with-elevenlabs.html` were generated from a mixed card: their contents list and description carried a neighbouring book's chapters. Corrected here. |
| 17 | the `"offers"` block is removed | The archetype pages carry `{"@type":"Offer","availability":…,"url":…,"seller":…}` with no `price` key, from an older template variant. An Offer without a price is not a useful claim, so the template emits one only when the card states a price. |

Nothing else moves: the four markers are identical on all 783 pages, every other JSON-LD field is
identical, and the markup is identical down to whitespace.

## Applying it

````bash
python3 tools/build_missing_pages.py --refresh
git diff --stat          # expect exactly 19 files
python3 tools/test_build_missing_pages.py
python3 tools/build_sitemap.py --check     # page count does not change
````
