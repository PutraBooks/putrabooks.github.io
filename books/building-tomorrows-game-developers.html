Building Tomorrow's Game Developers

S$1.90 · DRM-free EPUB + PDF

A game is finished not when somebody runs out of ideas but when somebody decides, on evidence, to stop changing it. This book is about the work behind that decision: what game developers actually hold on to, how the roles differ, what the career path rewards, and what changes when the tools change. Its 9 chapters move from The Loop through The Long Path. Written for people considering, entering, or advising a career in game development. Part of Building Tomorrow's People.
